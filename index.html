ℹ️ About This Reference

The spawn table is embedded into the website so the page does not need to make live browser requests for every lookup. A GitHub Actions updater can regenerate the embedded database from the public/base source on its schedule, then GitHub Pages republishes the updated site.
The Recipe Builder combines three seasoning slots and totals their effects. Same-effect seasonings can stack. The recommended shiny recipe favors Starf Berry, rarity uses Golden Carrot or Glistering Melon Slice, and target recipes use matching type or egg-group bait. Enchanted Golden Apple is available manually, but it is not treated as the default priority.
The listed rarity labels come from the public/base spawn data used by the updater. Complex Cobblemon can change rarity weights, disable species, add custom conditions, or otherwise modify server-side spawning.
Complex Cobblemon is a server environment and may have private or server-side configuration that is not exposed in a complete public machine-readable spawn list. That means this reference is useful for planning, but in-game information should be treated as the final authority for Complex-specific behavior.
The updater is designed to run through GitHub Actions. Scheduled workflows can be delayed by GitHub, so the update time is approximate rather than guaranteed to occur at an exact minute.

⚠️ Complex Cobblemon Limitation / Disclaimer

This page does not claim to have access to Complex's private server configuration. Its spawn reference is based on public/base Cobblemon data. Complex may have custom spawn pools, altered rarities, disabled Pokémon, changed biome conditions, datapacks, or other server-specific settings.

Always verify important spawn information in-game on Complex Cobblemon.
