Cobblemon Shiny Hunting – Final Interactive Reference

Upload the contents of this folder to the root of the GitHub repository.

Interactive features:
- Spawn List: search, biome/rarity/type filters, sorting, Pokémon detail popup, Build Recipe
- Pokémon images beside names using the public PokeAPI sprite set
- Pokémon detail view shows known visual/form variants and shiny images
- Recipe Builder: Pokémon selection, goals, Poké Snack/Poké Bait, editable 3 seasoning slots, effect totals
- Seasonings: search, effect filtering, details, Use in Recipe
- About & Disclaimer: expandable information sections and changelog
- Enchanted Golden Apple is available as an optional manual seasoning, but automatic recipes do not prioritize it.
- GitHub Actions updater regenerates the embedded spawn database.

Important:
The spawn reference is public/base Cobblemon data and may not exactly match Complex Cobblemon's private/server-side configuration. The public spawn table does not expose a complete machine-readable list of Complex-specific form restrictions, so variant images are shown as visual reference and not as a guarantee that every variant spawns on Complex.
